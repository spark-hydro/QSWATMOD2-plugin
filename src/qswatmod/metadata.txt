changelog=2.11.0
    - Linux support: the SWAT-MODFLOW3 program for Linux (swatmf3) is included and used by the Run button.
    - The linking step no longer needs CreateSWATMF.exe: a Python version writes the same files on Windows, Linux and macOS.
    - Works with Python 3.12 and NumPy 2 (no distutils; NumPy names fixed in the bundled FloPy); starts when the QGIS profile has no locale setting.
    - New ways to install: ZIP, install.sh (Linux), install.ps1 (Windows) and a QGIS plugin repository (plugins.xml). See the README.
    - Needs QGIS 3 (Qt5); tested with QGIS 3.44 LTR on Linux. Not ported to QGIS 4 (Qt6) yet.
